# Versioning Policy

Use Semantic Versioning once the product begins formal releases:

```text
MAJOR.MINOR.PATCH
```

- **MAJOR** — incompatible product or API change.
- **MINOR** — backward-compatible feature.
- **PATCH** — backward-compatible defect or operational fix.

Pre-release builds may use `0.x.y` and suffixes such as `-rc.1`.
