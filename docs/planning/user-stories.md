# User Stories

## Sprint 1

### US-001 — Submit a project request

As a visitor, I want to submit structured project information so Mad Mallard Solutions can understand and respond to my need.

Acceptance:

- required fields are validated;
- the request is persisted;
- a private conversation is created;
- configured notification email is sent;
- the visitor receives a usable confirmation.

### US-002 — Start an async conversation

As a visitor, I want to ask a quick question and receive a private link so I can continue later without creating an account first.

### US-003 — Leave feedback

As a customer, I want the option to rate a response so the business can improve without forcing me to complete a survey.

### US-004 — Register

As a customer, I want to create an account using my email and password so I can access my activity securely.

### US-005 — Verify email

As the platform, I want to verify ownership of an email address before activating sensitive account capabilities.

### US-006 — Reset password

As a customer, I want a safe password-reset flow that does not disclose whether another person's account exists.

### US-007 — View dashboard

As a customer, I want to see my requests, conversations, and recent activity in one place.

### US-008 — Manage profile

As a customer, I want to update my name, email, and password.

### US-009 — Administer interactions

As an administrator, I want to view queues, open conversations, reply, add internal notes, assign status/priority/tags, and close work.

### US-010 — Deploy reproducibly

As an operator, I want Terraform and deployment automation to reproduce the intended runtime without manual application edits.
