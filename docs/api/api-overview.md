# API Overview

The current API is an internal HTTP interface used by server-rendered pages and browser JavaScript. It is not yet a supported third-party API.

## Route domains

- public content and forms;
- conversation access and messaging;
- customer authentication and account;
- admin authentication and operations;
- static assets.

## Future external API

External clients will use `/api/v1/` with documented authentication, rate limits, problem details, and deprecation policy.
