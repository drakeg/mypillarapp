# Support

For help using or deploying Mad Mallard Platform, use GitHub Discussions first:

- **Q&A:** https://github.com/drakeg/mypillarapp/discussions/categories/q-a
- **Ideas:** https://github.com/drakeg/mypillarapp/discussions/categories/ideas
- **All Discussions:** https://github.com/drakeg/mypillarapp/discussions

Use GitHub Issues for confirmed defects, scoped implementation work, or actionable repository problems.

When asking for help, include the relevant operating system, deployment method, Docker/Compose details, application behavior, and logs where appropriate. Remove secrets, credentials, tokens, private customer data, and other sensitive information before posting.

Security vulnerabilities should not be posted in public Discussions or Issues. Follow the repository's security reporting process when one is available.
