# Development Workflow

## Principles
- GitHub main is the source of truth.
- Sprint-scoped changes only.
- Modify only files required for the active task.
- Documentation may be committed directly to main.
- Protect admin, Terraform and infrastructure unless explicitly in scope.

## Coding Process
1. Verify repository baseline.
2. Implement targeted change.
3. Run validation.
4. Update documentation and changelog.
5. Deploy.
